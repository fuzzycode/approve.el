  • The rows are approve-list.el's, shared with the search (D38). Columns: state (● open, ◌ draft, ⮌ merged, ⊘ closed), number, title (drafts dimmed), repository, author, updated, checks of the last commit (✓ ✗ ◐ ·), GitHub's review decision (✓ approved, ✗ changes requested, ○ review required, · none).
  • approve-list-columns says which columns, in what order and how wide; the title takes what is left. Whether an unread mark joins them waits for notifications (Q6).
  • M-x approve-dashboard and g load every list again; a list keeps its rows meanwhile, with ⟳ loading… on its heading. A heading counts what GitHub finds; when a list shows fewer, its last line says … 3 more · o show them on GitHub.
  • On a list's heading, o opens its search on GitHub and y copies it. T folds every list, O every list but the one at point (in evil za zo zc the list at point, zM/zR every list, zp the others). A token error is shown once, for the whole dashboard.
