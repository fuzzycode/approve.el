The PR buffer

Header, pending review, description, checks, commits, conversation, files and the diff with inline threads. Single and split layout, header line, loading and error states. Sections collapse on click.

Reviewing

Commenting on a range, suggestions, replies with quotes, the dispatch menu, submitting a review, confirmations.

Finding PRs

Dashboard, search and its filter menu, opening by URL from anywhere, notifications.

Managing & more

Labels and other metadata, reactions, merging, checks, re-reviewing after a push, the whole-file view, jumping, filtering the diff, eldoc.

Your clone

Review feedback in the buffers you edit: threads folded to their bubbles, edited lines, the mode line, the feedback dispatch, and finding a branch's PR and a PR's clone.

Flows

How the pieces talk, the shared action pipeline, and all scenarios F01–F23 as diagrams.

Icons

Four nerd-icons sets compared (Material Design, Codicons, Font Awesome, Octicons), side by side and in context. The picker at the top right applies a set to every page.

About these pages

  • Colours are the faces of the author's theme, doom-rose-pine-moon, read from the running Emacs. The theme button switches to rose-pine dawn: every Approve face inherits from theme faces (D16), so any theme works.
  • Icons are Approve's chosen nerd-icons set, Material Design (D31); they need a Nerd Font, such as JetBrainsMono Nerd Font, installed locally. The picker at the top right switches to the Unicode fallbacks (the other form of approve-icon) or to the other sets compared on Icons.
  • Keys shown are the Emacs ones from the draft key table in ui.org; the mode line shows evil's state (<N>, <I>) because the author uses evil.
  • Mockups are plain HTML and CSS (assets/). The flow diagrams are generated: edit flows/flows.gv or flows.src.html and run make docs (graphviz).
