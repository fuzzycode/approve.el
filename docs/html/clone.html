  • Nothing goes in the fringes, which are diff-hl's, Flymake's and the like, nor in the lines' text. Nothing marks the PR's changes either: the buffer is for editing, and diff-hl or Magit show what changed.

Keys approve-feedback-command-map · D46

The mode binds no key in your buffers but evil's ]t and [t. Its commands are in approve-feedback-command-map, for you to bind, under a leader key for example:

(keymap-set approve-feedback-mode-map "C-c a" approve-feedback-command-map)

  • ? dispatch · TAB fold the line's threads · T all · n/p next/previous unresolved thread (evil: ]t/[t)
  • c s comment, suggest · r R e k + on the line's threads · C on the pull request
  • RET the PR buffer at this line · P pick another PR · g refresh · o browser · S X submit, discard
  • In the PR buffer and the file view, f (evil: gF) opens the line, thread or file at point in your clone; F and gf still open Approve's file view.
