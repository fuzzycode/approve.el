@bob — Bob Smith
  • Reviewer marks: ✓ approved, ✗ changes requested, 💬 commented, ○ requested.
  • Your pending review only appears when one exists; its heading counts the comments, replies included.
  • File list: each file's counts, a diffstat bar and its threads on the whole file (the diff's “On this file”); its heading sums the unresolved ones. Which files are viewed is in the diff.
  • Diff file headings: the viewed mark (✓ viewed, dim; · not viewed; ↻ viewed but changed since, GitHub's DISMISSED; the Diff heading counts them), an icon of the change (+ added, ~ modified, − deleted, → renamed, ⧉ copied, ⚙ mode changed), then the path; the size is in the file list. At the right edge, lined up, the threads on its lines (outdated ones too); the Diff heading sums the unresolved ones. A moved file reads internal/engine/{queue.go → scheduler.go}, as in git's diffstat; a path too long for its room loses whole directories in the middle (internal/…/page.tmpl).
  • A diff line with threads has a speech bubble and their count at the right edge (dim when all are resolved), on the line's background but not in its colour. The line folds its threads (click it, or TAB on it or in them); only the bubble stays. Lines whose threads are all resolved start folded, as does Outdated. T folds every thread in the diff, or unfolds them all (zM / zR in evil), and files expanded later follow. O (zp) folds every section but the one at point, and in the diff every file but its own. Key hints (r reply · R resolve) can be turned off.
  • Thread marks (💬 N: the bubbles, the counts of file headings and of the file list) are neutral, except one counting a thread that asks for changes: unresolved, started in a review that requested changes, while that review is its author's latest verdict. That mark is red, until the thread is resolved, the review dismissed, or its author approves (D34).
